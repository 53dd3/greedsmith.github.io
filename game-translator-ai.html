Game Translator AI

Automatisation de la traduction de jeux vidéo par intelligence artificielle

Prototype fonctionnel — en phase de test

Contexte

Game Translator AI est un outil développé en Python qui automatise la traduction de jeux vidéo utilisant le moteur Ren'Py. L'objectif est de réduire considérablement le travail manuel nécessaire pour traduire des jeux comportant un très grand volume de dialogues.

Objectifs

  • Automatiser l'analyse des fichiers de traduction Ren'Py
  • Traiter de grands volumes de dialogues par lots
  • Maintenir la cohérence linguistique via un glossaire
  • Préserver intégralement la syntaxe et le code du moteur
  • Générer des fichiers directement utilisables dans le jeu

Technologies

Python LM Studio API compatible OpenAI JSON Ren'Py Traitement par lots Automatisation

Fonctionnalités

🔍

Analyse des fichiers

Le programme parcourt les fichiers .rpy du jeu afin d'identifier les entrées de traduction à compléter.

📦

Traduction par lots

Les textes sont regroupés en blocs pour permettre le traitement de volumes importants de dialogues.

📖

Traduction contextualisée

Le modèle reçoit des instructions, des règles linguistiques et un glossaire afin d'améliorer la cohérence des traductions.

🔒

Préservation du code

Les variables, balises et éléments spécifiques à Ren'Py qui ne doivent pas être traduits sont préservés intégralement.

📝

Génération des traductions

Le programme génère et remplit les fichiers de traduction français dans la structure attendue par Ren'Py.

💾

Suivi de progression

Le système conserve des informations sur l'avancement du traitement afin de permettre sa reprise après une interruption.

Fonctionnement technique

Le traitement se déroule en plusieurs étapes enchaînées, de l'analyse initiale des fichiers jusqu'à la génération des traductions finales.

1

Analyse des fichiers

Décompilation et lecture des fichiers du jeu pour en extraire la structure.

2

Identification des entrées

Repérage de toutes les entrées de traduction à compléter dans les fichiers .rpy.

3

Découpage en lots

Les textes sont regroupés en blocs de taille optimale pour le traitement par le modèle.

4

Envoi à LM Studio

Chaque lot est envoyé au modèle de langage local avec les instructions, règles et glossaire.

5

Réception JSON

Les traductions sont reçues sous forme structurée au format JSON.

6

Écriture des fichiers

Les résultats sont écrits dans les fichiers de traduction Ren'Py, dans la structure attendue par le jeu.

7

Sauvegarde de la progression

L'avancement est enregistré à chaque lot, permettant de reprendre le traitement après interruption.

Après génération, l'utilisateur sélectionne le français dans les options du jeu — aucune étape supplémentaire n'est nécessaire.

Contrôle qualité

Améliorer la vérification automatique de la qualité des traductions produites.

Optimisation des volumes

Optimiser le traitement pour mieux gérer les très gros volumes de texte.
