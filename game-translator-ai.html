Game Translator AI

Automatisation de la traduction de jeux vidéo par intelligence artificielle locale et préservation syntaxique.

PROTOTYPE FONCTIONNEL EN PHASE DE TEST 100% EXÉCUTION LOCALE
02 / CONTEXTE TECHNIQUE & OBJECTIFS
TRAITEMENT BATCH & SYNTAXE
// 01. CONTEXTE

Contexte Opérationnel

Game Translator AI est un outil développé en Python qui automatise la traduction de jeux vidéo utilisant le moteur Ren'Py. L'objectif est de réduire considérablement le travail manuel nécessaire pour traduire des jeux comportant un très grand volume de dialogues.

// 02. OBJECTIFS

Objectifs du Système

  • Automatiser l'analyse des fichiers de traduction Ren'Py (.rpy)
  • Traiter de grands volumes de dialogues par lots continus
  • Maintenir la cohérence linguistique via un glossaire contextuel
  • Préserver intégralement la syntaxe et le code interne du moteur
  • Générer des fichiers directement utilisables dans le build final
Python LM Studio API compatible OpenAI JSON Structuré Ren'Py Engine Traitement par lots Automatisation locale
03 / MODULES & FONCTIONNALITÉS
ARCHITECTURE FONCTIONNELLE DÉTAILLÉE
[01 // PARSER]

Analyse des fichiers

Le programme parcourt les fichiers .rpy du jeu afin d'identifier les entrées de traduction à compléter.

[02 // BATCH]

Traduction par lots

Les textes sont regroupés en blocs pour permettre le traitement de volumes importants de dialogues sans dépasser les fenêtres de contexte.

[03 // CONTEXT]

Traduction contextualisée

Le modèle reçoit des instructions, des règles linguistiques et un glossaire afin d'améliorer la cohérence des traductions.

[04 // SYNTAX]

Préservation du code

Les variables, balises et éléments spécifiques à Ren'Py qui ne doivent pas être traduits sont préservés intégralement.

[05 // GENERATOR]

Génération des traductions

Le programme génère et remplit les fichiers de traduction français dans la structure attendue nativement par Ren'Py.

[06 // CHECKPOINT]

Suivi de progression

Le système conserve des informations sur l'avancement du traitement afin de permettre sa reprise instantanée après une interruption.

04 / PIPELINE D'EXÉCUTION TECHNIQUE
SÉQUENCEMENT ÉTAPE PAR ÉTAPE
01

Analyse et décompilation des fichiers

Décompilation et lecture des fichiers du jeu pour en extraire la structure syntaxique et les chaînes de texte.

02

Identification des entrées de traduction

Repérage automatisé de toutes les entrées de traduction à compléter dans les fichiers .rpy.

03

Découpage optimisé en lots (Batching)

Les textes sont regroupés en blocs de taille optimale pour le traitement continu par le modèle LLM local.

04

Transmission à LM Studio / Local LLM

Chaque lot est envoyé au modèle de langage local avec les consignes strictes, les règles grammaticales et le glossaire.

05

Réception & Validation JSON

Les traductions sont reçues sous forme rigoureusement structurée au format JSON et vérifiées avant écriture.

06

Écriture des fichiers de traduction

Les résultats validés sont écrits dans les fichiers de localisation Ren'Py, dans l'arborescence native du jeu.

07

Sauvegarde de l'état (Checkpointing)

L'avancement est enregistré sur disque à chaque lot, permettant de reprendre le pipeline sans aucune perte en cas d'arrêt.
